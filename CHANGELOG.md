# Release notes

## 0.9.2

The status indicator follows USB scanner availability and appears beside the scanner status. The touchscreen title identifies Paperless as the destination.

## 0.9.1

Page mode groups the retained sides of each physical sheet. Receipt capture uses the front only. Document cleanup no longer adds white padding around the PDF image.

## 0.9

French and English touchscreen labels and progress across overlapping jobs.

## 0.8

LVGL touchscreen controls for the four scan modes, capture and multipass jobs.

## 0.7

Persistent Paperless delivery queue with inbox-tag verification.

## 0.6

Persistent processing queue. A new batch can start while an earlier one is being processed.

## 0.5

Automatic filenames, progress events and text checks for near-blank pages.

## 0.4

Version 0.4 uses English commands, options, JSON fields, events and report keys. Update external clients together with the Pi. The installer replaces the previous button service. Existing configuration keys and saved mode names are read automatically. The output location configured on an existing installation is preserved. Historical reports retain their original keys.
